## Overview

The **SHL Conversational Agent** is an intelligent recommendation system that helps hiring teams find the right assessment tools from the SHL Labs catalog. Using advanced AI techniques like RAG (Retrieval-Augmented Generation), semantic search, and vector embeddings, the agent understands user requirements and provides highly relevant assessment recommendations.

The system prevents hallucination by only recommending assessments from the official SHL catalog and handles complex multi-turn conversations with context awareness.

---

## Features

✅ **Intelligent Assessment Recommendations** - Uses AI to recommend SHL assessments based on hiring needs  
✅ **Semantic Search** - FAISS-powered vector similarity search for precise matching  
✅ **RAG Implementation** - Combines conversation history with catalog context for accurate recommendations  
✅ **Multi-turn Conversations** - Maintains conversation history and context awareness  
✅ **Hallucination Prevention** - Only recommends assessments explicitly in the SHL catalog  
✅ **FastAPI Backend** - High-performance REST API with async support  
✅ **Health Check Endpoint** - Built-in monitoring for deployment platforms  
✅ **Timeout Safety** - Automatic detection of approaching timeout limits  
✅ **JSON Response Format** - Structured responses with recommendations and conversation flags

## Installation

### 1. Clone or Extract the Project
```bash
cd Assignment
```

### 2. Create Virtual Environment
```bash
# On Windows
python -m venv venv

# On macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Set Up Environment Variables
Create a `.env` file in the project root:
```dotenv
GEMINI_API_KEY=your_google_gemini_api_key_here
```

**To get your API key:**
- Visit [Google AI Studio](https://aistudio.google.com/app/apikey)
- Create a new API key
- Copy it to your `.env` file

### 5. Prepare the Data

**Option A: Fetch Fresh Catalog**
```bash
# Fetch the latest SHL assessment catalog
python scripts/scrape_catlog.py
```

**Option B: Use Existing Catalog**
If `data/shl_catalog.json` already exists, skip the above step.

### 6. Build Vector Index
```bash
# Create the FAISS vector index for semantic search
python scripts/build_index.py
```

This will:
- Load `data/shl_catalog.json`
- Generate embeddings for all assessments using `all-MiniLM-L6-v2`
- Create `data/faiss_index.bin` for fast similarity search

### Chat Endpoint

**POST** `/chat`

Sends a message to the SHL assessment recommender agent.

**Request Body:**
```json
{
  "messages": [
    {
      "role": "user",
      "content": "I need to assess C++ developers with 5 years of experience"
    }
  ]
}
```

**Response:**
```json
{
  "reply": "Based on your requirements, I recommend the following assessments...",
  "recommendations": [
    {
      "name": "C++ Assessment Advanced",
      "url": "https://example.com/assessment",
      "test_type": "Technical Assessment"
    }
  ],
  "end_of_conversation": false
}
```

**Response Fields:**
| Field | Type | Description |
|-------|------|-------------|
| `reply` | string | The agent's response text |
| `recommendations` | array | List of recommended assessments |
| `end_of_conversation` | boolean | Whether the conversation has concluded |

**HTTP Status Codes:**
- `200 OK` - Successful response
- `500 Internal Server Error` - Server error (check logs)

## Project Architecture

### System Design

```
┌─────────────────────────────────────────────────────────────────┐
│                      Client Application                          │
└────────────────────────────┬────────────────────────────────────┘
                             │
                      HTTP Request
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                    FastAPI Application                           │
│                     (src/main.py)                                │
│  ┌─────────────────┐      ┌────────────────────────────────┐    │
│  │ /health         │      │ /chat (POST)                   │    │
│  │ Health Check    │      │ Chat Endpoint                  │    │
│  └─────────────────┘      └────────────────┬───────────────┘    │
│                                            │                    │
│                                      Processes                  │
│                                            │                    │
└────────────────────────────────────────────┼───────────────────┘
                                             │
                                             ▼
                    ┌─────────────────────────────────────┐
                    │    RAG Agent Logic                  │
                    │    (src/agent.py)                   │
                    │                                     │
                    │  1. Combine user queries            │
                    │  2. Embed with SentenceTransformer  │
                    │  3. Search FAISS index              │
                    │  4. Retrieve context                │
                    │  5. Call Gemini API                 │
                    │  6. Parse JSON response             │
                    └──────┬────────────────┬──────────────┘
                           │                │
              ┌────────────▼───┐   ┌────────▼────────┐
              │  FAISS Index   │   │  Google Gemini  │
              │  (Semantic     │   │  API (LLM)      │
              │   Search)      │   │                 │
              └────────────────┘   └─────────────────┘
              
              ┌─────────────────────────────────┐
              │  SHL Catalog (shl_catalog.json) │
              │  Embeddings + Metadata          │
              └─────────────────────────────────┘
```

### Data Flow

1. **User Query** → FastAPI `/chat` endpoint
2. **Message Processing** → Combine all previous user messages
3. **Vector Embedding** → Convert combined query to embeddings
4. **Semantic Search** → FAISS finds top 30 similar assessments
5. **RAG Context** → Format retrieval results as context
6. **LLM Processing** → Send to Google Gemini with system prompt
7. **Response Parsing** → Parse JSON response with recommendations
8. **Return to Client** → Send structured response

## Scripts

### `scripts/scrape_catlog.py`

**Purpose**: Fetches the SHL product catalog from the remote API

**What it does:**
- Downloads assessment catalog from SHL's remote JSON endpoint
- Handles JSON parsing with control character cleanup
- Maps raw data to standardized format with fields: `name`, `url`, `test_type`, `description`
- Saves processed catalog to `data/shl_catalog.json`

**Usage:**
```bash
python scripts/scrape_catlog.py
```

**Output**: Creates/updates `data/shl_catalog.json` with ~100+ assessment items

**Key Features:**
- Automatic directory creation for `data/` folder
- Robust error handling for malformed JSON
- Fallback mechanisms for missing fields

---

### `scripts/build_index.py`

**Purpose**: Creates FAISS vector index for fast semantic search

**What it does:**
- Loads `data/shl_catalog.json`
- Uses `SentenceTransformer('all-MiniLM-L6-v2')` to embed assessments
- Normalizes embeddings for cosine similarity
- Creates FAISS IndexFlatIP (Inner Product) index
- Saves index to `data/faiss_index.bin`

**Usage:**
```bash
python scripts/build_index.py
```

**First Run**: ~1-2 minutes (downloads embedding model)  
**Subsequent Runs**: ~30 seconds

**Output**: Creates `data/faiss_index.bin` (~50-100MB depending on catalog size)

## How It Works

### 1. Initialization Phase

When `src/agent.py` starts:
```python
# Load catalog data
with open("data/shl_catalog.json") as f:
    shl_catalog = json.load(f)

# Load FAISS index
faiss_index = faiss.read_index("data/faiss_index.bin")

# Load embedding model
embedder = SentenceTransformer('all-MiniLM-L6-v2')
```

### 2. Request Processing

When a user sends a chat message:

```python
# Step 1: Combine all user messages for better context
user_queries = [msg.content for msg in messages if msg.role == "user"]
combined_search_query = " ".join(user_queries)

# Step 2: Embed the combined query
query_vector = embedder.encode([combined_search_query], convert_to_numpy=True)
faiss.normalize_L2(query_vector)

# Step 3: Search FAISS index
distances, indices = faiss_index.search(query_vector, top_k=30)

# Step 4: Retrieve matching catalog items
context_chunks = [shl_catalog[idx] for idx in indices[0] if idx != -1]

# Step 5: Call Gemini API with RAG context
response = client.chats.create(
    model='gemini-2.5-flash',
    config=GenerateContentConfig(
        system_instruction=SYSTEM_PROMPT,
        response_mime_type="application/json",
        response_schema=ChatResponse,
        temperature=0.2
    ),
    history=formatted_history
)

# Step 6: Parse and return response
return json.loads(response.text)
```

### 3. Safety Mechanisms

**Hallucination Prevention**: 
- System prompt explicitly instructs AI to only use items from the catalog
- All recommendations are verified against catalog items

**Timeout Handling**:
- Monitors execution time
- Issues warning if approaching 30-second limit (cloud timeout)

**Error Handling**:
- Try-catch blocks around API calls
- HTTPException returns with clear error messages

## Troubleshooting

### Issue: `FAISS index not found`
**Solution**: Run `python scripts/build_index.py` after fetching the catalog

### Issue: `GEMINI_API_KEY not found`
**Solution**: Ensure `.env` file exists with `GEMINI_API_KEY=your_key`

### Issue: `shl_catalog.json not found`
**Solution**: Run `python scripts/scrape_catlog.py` to fetch the catalog

### Issue: Slow responses
**Solution**: Increase `top_k` in `retrieve_context()` function or reduce it for speed vs accuracy trade-off

### Issue: Model not downloading
**Solution**: First run may take 1-2 minutes. Check internet connection and disk space
